# RGARAGE-Builds

Builds para Windows de ports e recompilações de jogos de **código aberto**, feitos pelo [RGARAGE HUB](https://github.com/DuarttBR/RGARAGE-HUB-Releases).
_Windows builds of open-source game ports and recompilations, made by RGARAGE HUB._

- Cada release é um port, compilado a partir do código do autor, sem nenhuma modificação de jogabilidade.
- Todo pacote leva a **licença do projeto original**, o arquivo `CREDITOS.txt` (autor, repositório, versão do código) e o **código-fonte usado** (`fonte-*.zip`), como as licenças abertas pedem.
- **Nenhum jogo vem junto.** Os ports usam os arquivos da sua própria cópia do jogo.
- Builds não oficiais: problemas do port vão para o repositório do autor; problemas do build, para as issues daqui.
- Autor de um destes projetos e não quer o build aqui? Abra uma issue e ele sai na hora.

`receitas/` tem os passos de cada build e `builds.json` é a lista que o hub lê.
